# Earth Regenerative Inc. website

Next.js App Router starter for ERI's institutional website.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

1. Create a new GitHub repository and upload this project.
2. In your existing Vercel account, choose **Add New > Project**, import the repository, and deploy.
3. Add `earthregenerativeinc.com` in **Project > Settings > Domains**.
4. Set the DNS records at Namecheap to the exact values Vercel displays.

## Before public launch

- Verify company legal name, governance status, and all institutional claims.
- Replace placeholder contact email with a verified working address.
- Review all public claims and REI disclosures with appropriate counsel.
